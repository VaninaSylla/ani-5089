## Exercice - DEUX YEUX, DEUX IMAGES
### 1- Les trois cadences
pour calculer la duree disponible par image : 
duree d'une image = 1000/frequence en hz

le systeme utilise 8ms
le temps restant pour le codes est donc :
temps restant = duree d'une image - 8ms

 a 72 hertz : 
 duree d'une image = 1000/72 = 13,9ms
 temps restant = 13,9 ms - 8ms = 5,9 ms

 a 90 hertz:
 duree d'une image = 1000/90 = 11,1ms
 temps restant = 11,1 ms - 8ms = 3,1 ms

  a 120 hertz:
duree d'une image = 1000/120 = 8,3ms
 temps restant = 8,3 ms - 8ms = 0,3 ms

 ## Resultats 
- a 72hz il reste 5,9ms pour le code
- a 90hz il reste 3,1ms pour le code
- a 120hz il reste 0,3ms pour le code
