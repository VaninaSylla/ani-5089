Sortie standard du programme :

    Journal de l'exercice : l'image qui n'existe pas
    Fichier demande : murs/nexistepas.png

    charge : false, valide : false, largeur : 0, hauteur : 0
    [disque] fopen("murs/nexistepas.png") = ECHEC (fichier absent)

    [textures] Load("murs/nexistepas.png") = handle id=4 (non nul)
    [textures] id des textures par defaut du moteur :
    [textures]   White1x1  id=1
    [textures]   Black1x1  id=2
    [textures]   Normal1x1 id=3
    [textures]   Error     id=4  (texture magenta "manquante")
    [textures] le handle rendu pointe-t-il la texture d'erreur ? OUI
    [textures] le handle rendu pointe-t-il le blanc 1x1 ? non

    Consequence : un fichier absent ne renvoie pas un pointeur nul et ne plante
    pas. La bibliotheque rend un handle NON NUL qui pointe la texture d'erreur
    (magenta 1x1) : le mur est bien dessine, mais en magenta uni. C'est le
    panneau "image manquante" du moteur.

    [capture] frame 120 -> mur-absent.png
    [exo2] capture armee : frame 120 -> mur-absent.png
    [toneldr] copie de ToneLDR 1280x720 ARMEE dans FXAA_Final
    [toneldr] transient ToneLDR 1280x720, lignes telles que stockees -> mur-absent.png : ecrit
    [exo2] fin du programme

Sortie d'erreur du moteur (la ligne qui nomme le fichier) :
